# ИИ-сервер для GitHub Pages

Подготовлен Cloudflare Worker. Без развёртывания сервера и секретного ключа ИИ-проверка не включена: сайт не показывает выдуманную оценку.

## Что нужно владельцу

1. Аккаунт Cloudflare с Workers и Durable Objects.
2. Ключ проекта OpenAI с доступом к текстовой и аудиомодели. В проекте OpenAI настройте бюджет/уведомления. Стоимость API отдельная от ChatGPT.
3. После установки зависимостей в этой папке выполнить `npx wrangler login` и пройти вход самостоятельно.
4. Выполнить `npx wrangler secret put OPENAI_API_KEY` и ввести ключ в защищённый запрос терминала. Не отправляйте его в чат, исходники, config.json или настройки браузера.
5. Выполнить `npm run deploy`. Полученный URL Worker вписать в `../config.json` в `apiBase`, без завершающего `/assess`. Отправить изменение в main.
6. Проверить `/health`: `ready:true`. Провести калибровочные проверки на работах с экспертной оценкой до использования для диагностики.

Зависимости: `npm install` в папке server. Node.js 22+; Wrangler 4. Lock-файл включён в репозиторий. Модели задаются в wrangler.jsonc, при недоступности конкретной модели настройте разрешённую эквивалентную модель с нужными модальностями и повторно проверьте качество.

## Границы реализации

- Письмо: официальный подсчёт объёма → обрезка проверяемого фрагмента при превышении допуска → оценка критериев моделью → проверка схемы, диапазонов и оснований → серверный пересчёт суммы и К1=0.
- Говорение: WAV всех ответов по заданию → аудиомодель, которая получает сам звук → предварительный разбор по рубрике → тот же проверяемый расчёт. Одна расшифровка не подменяет анализ произношения.
- Неуверенный аудиоанализ, отказ, недостающий критерий или техническая ошибка не превращаются в 0 баллов. Итог остаётся невыставленным.
- У ИИ нет гарантии экспертной точности. Каждая автоматическая работа отмечается «предварительно», требует экспертной калибровки; при споре нужна ручная проверка. Непродуктивность/плагиат надёжно автоматически не определяются и не служат причиной обнуления со стороны ИИ.
- Ответ, звук и промпт не пишутся в журнал Worker. Запросы к OpenAI отправляются с store:false. Это не обещает нулевого хранения у провайдера: применяются актуальные условия его обработки данных.
- На сайте требуется отдельное согласие перед отправкой. Локальные записи сами по себе на сервер не отправляются.
- Глобальная атомарная квота по умолчанию: 30 проверок/сутки, 5 на IP. Счётчики в Durable Objects. CORS не является авторизацией и не защищает от прямого злоупотребления API. Для массового публичного запуска добавьте серверную авторизацию/Turnstile и пользовательские квоты. Текущий лимит ограничивает ущерб от злоупотребления, но может привести к исчерпанию общего доступа.
- Перед публичным учебным запуском отдельно проверить обработку персональных данных, условия провайдера для аудитории и доступность сервиса в регионе пользователей. Не отправлять реальные работы до согласия пользователя.

Тесты модели используют заглушки. Реальные вызовы OpenAI не выполнялись: ключ API отсутствует. Модуль развёртывания подготовлен, но без доступа к Cloudflare не опубликован.
