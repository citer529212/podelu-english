# По делу — английский ОГЭ и ЕГЭ

Тренажёр: https://citer529212.github.io/podelu-english/

44 авторских задания с объяснениями, повторение ошибок, памятки, письмо с сохранением черновика и запись устных ответов.

Прогресс хранится локально в браузере. В этой версии нет ИИ-оценки, полного пробного экзамена и банка аудирования. Учебные упражнения не являются официальными заданиями ФИПИ.

## Публикация

GitHub Pages публикует корень ветки main. Для обновления измените файлы и отправьте коммит в main.

## Локальный запуск

python3 -m http.server 8000
