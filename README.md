## ИИ-сервер

Cloudflare Worker подготовлен и проверен сборкой dry-run. Реального развёртывания нет: нужны вход владельца в Cloudflare и ключ OpenAI. Инструкция: [server/README.md](server/README.md). Поле apiBase в config.json пустое; UI честно показывает, что автоматическая проверка не подключена. До независимой калибровки результат ИИ может называться только предварительным.

Ключ модели хранится только в серверных secrets. Прогресс и записи остаются в браузере; отправка на ИИ-сервер требует отдельного согласия. Установленные зависимости сервера не нужны статическому сайту и не публикуются в Git.

## Самостоятельная подготовка и личная библиотека

`learning.js` строит план по истории выбранного экзамена: микроупражнения, приоритетный блок и письмо/говорение. Ошибочные блоки возвращаются через день, успешные — через три дня. Это стартовое расписание практики, не доказательство освоения или прогноз балла. Длительность плана меняется с выбранным временем; история сохраняется в браузере.

Раздел `#library` принимает пользовательский PDF Трубаневой (ОГЭ 2026, скан 289 страниц) и папку с подпапками `Аудирование` / `Устная часть` и файлами `1.mp3`–`20.mp3`. Файлы хранятся только в IndexedDB текущего браузера. На сервер они не отправляются; в репозиторий не включены. Для другого скана можно уточнить страницу каждого варианта. Без поддержки выбора папки можно добавить MP3 к выбранному варианту отдельно. Автоматических баллов по несверенным OCR-ключам сборника нет.

При очистке данных сайта личная библиотека может быть потеряна: сохраняйте исходные файлы. Экспорт истории не включает PDF, аудио и записи речи. Восстановление из экспорта переносит микроупражнения, сессии и черновики; остальная история текущего устройства сохраняется.
